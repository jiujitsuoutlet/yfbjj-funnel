## Released change

The “Get Lifetime Access Now!” image on the lifetime offer is now an accessible one-click offer action. It uses the same server-owned, cookie-bound saved-card purchase handler as the existing lifetime CTA. The editor still treats the image as editable content and does not trigger a purchase from the editing canvas.

The live verification rule now requires exactly one clickable lifetime image and three lifetime accept actions total. An image-only button is only considered valid when it has a non-empty accessible label.
