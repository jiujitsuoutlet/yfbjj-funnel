On the live page, this button opens a Stripe-hosted checkout. This preview cannot create a session, customer, payment, subscription, or entitlement.

What happens when it goes live

  • The email address is captured firstIt is written to our own database before the handoff, so we keep the lead whether or not the sale completes.
  • The buyer lands on Stripe CheckoutStripe owns the hosted payment form and returns a signed completion event to this Worker.
  • Access follows the verified offer mappingThe signed event is recorded with the exact AutoCreator grant key selected for that offer.

Checkout stays locked until npm run preflight verifies the Stripe prices, AutoCreator grant keys, deadline, D1 database, and fulfillment implementation. Only then can PREVIEW_MODE become the exact string false.
