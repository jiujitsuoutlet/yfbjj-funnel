On the live page, this button opens the ThriveCart order form, where payment, coupons, VAT, and delivery are handled. This build has no cart link set, so it stops here instead.

What happens when it goes live

  • The email address is captured firstIt is written to our own database before the handoff, so we keep the lead whether or not the sale completes.
  • The buyer lands on ThriveCartThriveCart owns the order form, payment, coupons, VAT, upsells, and fulfilment.
  • ThriveCart takes it from thereThe post-purchase chain, including the one-click upsells, runs inside ThriveCart. This site's /thanks page is only a fallback destination.

To switch this off: set THRIVECART_BUNDLE_URL to the real cart link and PREVIEW_MODE to false in wrangler.toml, then run npm run preflight.
